# Ashford Railway Club app

- `index.html` - the app. Vercel serves this file. It must keep this exact name.
- `update-extra-staff.sql` - run once in Supabase (SQL Editor) to add "extra bar staff" to club events.
- `schema.sql` - the full database setup, for a brand-new Supabase project only. Don't run it on Club-APP.
